ℹ️ Sobre estas medições

A RAM total, disponível e usada são dados do sistema Android. A RAM PSS e a CPU são do processo deste aplicativo. O FPS é medido pela interface do aplicativo usando Choreographer. Estes dados não medem diretamente o FPS nem a CPU do Free Fire.

A leitura funciona na versão APK Android com a ponte Java configurada. Se abrir este HTML num navegador comum, a ponte nativa não estará disponível.
